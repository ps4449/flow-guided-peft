# Flow placement: exploratory experiment update

Our starting result was encouraging but left a placement question open. On ScienceQA, flow-pruned LoRA on layers 0–15 reached **81.36 ± 0.31%** across seeds 0–2, compared with **81.21 ± 0.41%** for uniform LoRA. It used 2,097,152 trainable adapter parameters instead of 4,194,304. This is approximately the same observed accuracy at half the adapter budget. Flow and gradient-based selection both chose layers 0–15, leaving open whether either adds guidance beyond depth.

Because knockout windows measure regions rather than isolated layers, we first asked whether flow suggested two separate useful regions. The best pair of eight-layer regions was **0–7 and 9–16**. It shared **15 of 16 layers** with the existing allocation, replacing only layer 8 with layer 16. We skipped training because it would barely change the scientific comparison. This negative result ruled out the proposed region constraint as a useful new experiment.

That early concentration led us to check the knockout window itself. With width nine, center 4 blocks layers 0–8, while center 5 blocks 1–9. The sharp importance drop coincides with layer 0 leaving, even though the width stays nine. Layer 9 also enters, so this does not isolate layer 0's causal contribution. We compared widths three and nine on the same **200 correctly answered calibration questions**, keeping prompts and inference settings matched. Rankings changed: Spearman correlation was **0.686**, with **4/8** shared top-eight and **14/16** shared top-sixteen layers. However, the new top sixteen still shared **15/16** historical early layers and failed our stability screen. We therefore prepared no new training configuration. Raw knockout magnitudes across window sizes are not directly equivalent.

We next separated the two pathways, using all **989** existing window-nine calibration examples. Image→Question remained early-focused, with ambiguity around its selection cutoff. Question→Last selected **layers 9–16**, sharing only **3/8** layers with combined flow. Its exact top-eight set recurred in **99.84% of 5,000 paired bootstrap draws**. This gave us a distinct, stable allocation to test, although stability alone says nothing about downstream accuracy.

We trained Question→Last and a fixed middle control, **layers 12–19**, with the combined-flow seed-0 settings and the same **1,048,576** trainable parameters. On the same 2,017 held-out image questions, combined flow achieved **1605/2017 (79.57%)**, Question→Last **1572/2017 (77.94%)**, and fixed middle **1522/2017 (75.46%)**. The stable pathway ranking did not translate into a higher score than combined flow in this seed.

We then aligned every prediction by question ID and checked exact gold labels and the original scoring normalization. Combined minus Question→Last was **+1.636 percentage points**, with a 95% paired-question bootstrap interval of **[+0.446, +2.876]** and exact McNemar **p = 0.00899**. These tests describe evaluation-question uncertainty for the fixed checkpoints. They do not measure training-seed reliability or establish a reproducible method advantage.

Finally, we added **fixed early layers 0–7** as the final planned control. It tests whether early placement alone explains the combined-flow result. Its matched seed-0 run is **running / result pending** in this snapshot; no accuracy is claimed. Together, these follow-ups narrow the placement hypothesis while preserving useful rejected alternatives. Flow's unique superiority over gradient-based or simple depth-based selection remains unestablished.
