# Flow placement: completed exploratory experiments

Our main ScienceQA result raised a placement question. Flow-pruned LoRA on layers 0–15 achieved **81.36 ± 0.31%** across seeds 0–2, compared with **81.21 ± 0.41%** for uniform LoRA. It used **2,097,152** trainable adapter parameters instead of **4,194,304**: approximately the same observed accuracy at half the adapter budget. However, gradient-based selection chose the same layers 0–15. Could flow provide useful guidance beyond simply selecting early layers?

Across the sparse LoRA comparisons, all 32 original transformer layers stayed in place. We changed where adapters were trained; fewer adapters do not imply faster inference.

Because attention-knockout windows measure regions rather than isolated layers, we first searched for two separated eight-layer regions. The best pair was **0–7 and 9–16**, sharing **15/16** layers with the existing allocation and replacing only layer 8 with layer 16. We skipped training because this would barely change the comparison. The negative result rejected the region constraint as a useful new experiment.

That early concentration led us to examine window size. With width nine, center 4 blocks layers 0–8 and center 5 blocks 1–9. The importance cliff coincides with layer 0 leaving while layer 9 enters; it does not isolate layer 0's contribution. We compared widths three and nine on the same **200 correctly answered calibration questions**, with matched prompts and inference settings. Rankings changed: Spearman correlation was **0.686**, with **4/8** shared top-eight and **14/16** shared top-sixteen layers. Yet the new top sixteen retained **15/16** historical early layers and failed our stability screen. We prepared no new training configuration. Raw knockout magnitudes across window sizes are not directly equivalent.

We next separated Image→Question and Question→Last using all **989** existing window-nine calibration examples. Image→Question remained early-focused, with ambiguity near its selection cutoff. Question→Last selected **layers 9–16**, sharing only **3/8** layers with combined flow. Its exact top-eight set recurred in **99.84% of 5,000 paired bootstrap draws**. This supplied a distinct, stable allocation to test, although stable calibration rankings do not guarantee better adaptation.

We therefore trained Question→Last and a fixed middle control, **layers 12–19**, with the combined-flow seed-0 settings. Each used **1,048,576** trainable parameters and the same **2,017** held-out image questions. Combined flow, **layers 0–4 and 9–11**, scored **1605/2017 (79.57%)**; Question→Last scored **1572/2017 (77.94%)**; fixed middle scored **1522/2017 (75.46%)**. Combined minus Question→Last was **+1.636 percentage points**, with a 95% paired-question bootstrap interval **[+0.446, +2.876]** and exact McNemar **p = 0.00899**. The distinct pathway ranking did not improve this seed's accuracy.

The remaining question was whether combined flow benefited simply from including early layers. Our final matched control, **fixed layers 0–7**, completed with **1605/2017 (79.57%)**, exactly tying combined flow. After aligning unique question IDs, exact gold labels and the original scoring normalization, both were correct on **1,563** questions; each uniquely answered **42** correctly. The difference was **0.000 percentage points**, with a 95% paired-question bootstrap interval **[−0.892, +0.892]** and exact McNemar **p = 1.0**.

All planned experiments are complete. The strongest observation remains the sixteen-layer adapter-budget reduction. These follow-ups tested and rejected useful alternatives, but found no unique flow-placement advantage over the fixed early control in seed 0. The tie does not establish statistical equivalence. Paired tests describe evaluation-question uncertainty for fixed checkpoints, not reliability across training seeds. Superiority over gradient-based or simple depth-based selection remains unestablished.
